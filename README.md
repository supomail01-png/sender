# SK PRO 4.2

Professional email sender with live remote control.

## Quick Start

```bash
pip install -r requirements.txt
python server.py      # Terminal 1
python panel.py       # Terminal 2
```

## Features
- Users Management
- Build Client EXE (per user)
- Live Monitor (real-time online status)
- Remote View (live screenshots + control)
- Client Auto-Registration + Heartbeat
