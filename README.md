# SK PRO 4.2 - Complete Remote Control Panel

Professional email sender with live monitoring, remote control, and client management.

## Quick Start

```bash
pip install -r requirements.txt
python server.py      # Terminal 1
python panel.py       # Terminal 2
```

## Features

- Users Management (create/edit/delete)
- Build Client EXE (per user)
- Live Monitor (real-time online status)
- Remote View (live screenshots + mouse/keyboard control)
- Client Auto-Registration + Heartbeat
